Cascading — the board recedes while it plays itself out

Both boards run the same state, the same moves and the same timings. Only the greying differs. Both shrink the canvas alone — the pads hold their positions, so the board pulls back away from its own controls.

Both run buttons re-seed the same rigged staircase first, so every press starts from an identical board — press again to replay. Cascade runs uncapped, exactly like the shipped mode: four passes are guaranteed by the seed, and the spawns often add more. The grey should snap in, sharply, as the second pass begins.

One pass (forced) stops after the first pass. It is artificial — no board reliably stops after one, since the spawn lands behind the packed tiles and usually moves next go — but it reproduces the 200ms of an ordinary swipe so you can check nothing flashes. If it does flicker, nudge delay up: one pass is exactly 200ms (110 slide + 90 pop), so 200 is a photo finish and 240 is safe.
